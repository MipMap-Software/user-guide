# MANIFOLD Handheld LiDAR

## 1. Point Cloud Processing

Raw LiDAR data must first be processed in `MindCloud Studio`, then select `MipMap Export`.

Refer to the manufacturer's user manual for detailed procedures.

![](/img/en-img/manifoldexport.png)

---

## 2. Create New Project

Click New Project![](/img/en-img/newproject1.png), enter the project name, and select LiDAR as the task type.

![](/img/en-img/newproject.png)

---

## 3. Import Data

Click Import Preprocessed Data.

![](/img/en-img/importmpl.png)

Locate the `.mpl` file in the processing output directory and select it for import.

![](/img/en-img/manifoldmpl.png)

---

## 4. Select Outputs

Select a reconstruction template, or manually specify the required 3D output format and output coordinate system.

![](/img/en-img/manifoldoutputs.png)

---

## 5. Start Reconstruction

Click Start Reconstruction![](/img/en-img/start.png) to begin.

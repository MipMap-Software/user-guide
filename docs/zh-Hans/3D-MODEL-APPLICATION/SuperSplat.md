# SuperSplat编辑高斯模型教程

## 高斯模型导入SuperSplat

1. 打开SuperSplat https://superspl.at/editor
2. 顶部菜单：`文件 → 导入 → 选择高斯模型文件PLY/SOG`

![](/img/cn-img/supersplatimport.png)

3. 左侧可调整位置与旋转参数，将模型移到坐标轴中心并置平。

![](/img/cn-img/旋转模型.png)

---

## 编辑高斯模型

### 删除飞点

1. 下方工具栏，可灵活使用，选择需要删除的飞点。

2. 按键盘Delete可删除选中的飞点，Ctrl+Z可撤回操作。

![](/img/cn-img/选择.png)

### 调整色彩

若高斯模型色彩不符预期，可进行以下调整。

1. 左侧点击颜色，展开色彩参数调整面板，可按需调整。

2. 右侧点击设置图标，可在色调映射栏，选择需要的滤镜。

![](/img/cn-img/高斯色彩调整.png)

## 导出高斯模型

1. 顶部菜单：`文件 → 导出 → 选择PLY/SOG`

![](/img/cn-img/导出高斯.png)

2. 选择导出文件存放位置，点击导出，等待导出动画完成即可。


![](/img/cn-img/导出高斯2.png)

---

## 录制漫游渲染视频

1. 点击左下角时间线图标。
2. 右下角设置视频帧率与总帧数。
3. 点击下方时间线，添加漫游关键帧。
4. 点击播放，可预览漫游视频。

![](/img/cn-img/录制视频.png)

5. 顶部菜单：`渲染 → 视频`，选择视频参数设置。

![](/img/cn-img/渲染视频.png)

6. 点击渲染，选择视频存放位置，等待渲染动画完成即可。

![](/img/cn-img/渲染.gif)
